# 发布地区与线上资源交付修复（2026-10-31）

发布页可以选择“线上交付 / 无需邮寄”，适用于通过卡密、文本或链接交付的商品。切换后自动关闭自提；需要自动发送内容时，继续使用已有的自动发货货源绑定。

“发布地区”表示商品展示的省、市、区，不是买家收货地址，不要求街道或门牌号。当前仍要求选择发布地区；尚未用真实账号确认平台允许完全省略地区，因此没有自动删除位置参数。

## 修改内容

- Windows 目录版和单文件版都内置 `china_address_dict.json`，放在只读的 `app/resources/`，与程序旁的业务 `data/` 分开。构建校验会阻止缺少字典的目录包通过。
- 排除开发环境中其他工具携带的同名 ICU 动态库，避免覆盖 Qt 使用的 Windows 系统 ICU，导致冻结包启动时报导入错误。
- 地址字典加载失败时显示原因，并提供“重新加载”。保留省、市、区联动、清除及草稿恢复。
- 发布、编辑页和后端统一检查地区字段、六位数字行政区编码及经纬度范围。行政区字典没有具体地点的 POI ID，不再将它作为本地必填字段，也不使用区县编号伪造 POI ID。平台对具体类目或账号的额外要求仍以真实响应为准。
- 普通单规格发布接口允许 `shippingMode=none` 与 `freeShipping=false`，沿用现有无需物流的发布负载构造。普通发布尚未支持的固定运费选项在页面禁用，鱼小铺多规格原有选项保留。
- 恢复发布记录时保留原始参数和幂等键；“无需邮寄”及旧运费模式不再触发记录删除。缺少结果回执时按结果未知处理，禁止直接重发。已确认的平台结果仍可只修复本地状态。
- 发布确认摘要包含原记录的交付方式和发布地区，恢复请求按原记录中的规格数据选择发布接口。

## 验证范围

接口回归使用临时 SQLite 数据库和模拟的平台响应，验证线上交付与包邮负载、地区校验、相同幂等键不重复发布、未知结果禁止重发及本地修复。没有登录真实账号或创建平台商品。

内嵌 Chromium 检查新增地址字典接口与真实 Vue 控件操作：选择北京市东城区、清除、改选浙江省杭州市西湖区，以及切换线上交付后自动关闭并禁用自提。

本地结果：78 项后端、桌面及打包测试和 32 项前端测试通过；前端构建与修改文件的 ESLint 错误检查通过。最终目录版与单文件 EXE 均通过中文路径搬移、外部工作目录启动、移除开发 PATH 后的内嵌控制台与发布控件检查，图标资源校验通过。构建产物位于 `dist/publish-fix/`，验证报告位于 `reports/publish-frozen-directory.json`、`reports/publish-frozen-standalone.json` 和 `reports/publish-icon-build.json`。

真实账号发布、平台是否要求具体地点 POI、类目限制及实际交付，仍需实际联调确认。本次不向远端发布软件版本。
