# 桌面性能与界面清理

更新日期：2026-10-31。

## 启动与运行

- API 线程提前启动，与 Qt/Chromium 导入及窗口初始化重叠；即使 Qt 导入或窗口初始化失败，也先停止后端、等待 SQLite 退出，再释放实例锁。
- 原生网络探测移至单线程后台执行，每次完成后间隔 2 秒检查；界面定时器只读取已完成的结果，不等待 Windows 网络 API。同一时间最多一个探测，探测异常保留已知状态。
- 原生状态未变化时不重复设置状态栏和托盘；后台状态查询间隔 2 秒，暂停闸门仍同步生效。同原因、同版本的恢复请求共享正在执行的任务，避免每次界面 tick 重复对账。
- Chromium 在程序旁 `data/profiles/console/cache` 保留磁盘缓存。启动标签、网页底色使用一致背景，页面加载后切入控制台，减少白屏切换。
- 桌面入口延迟加载移动端；设置页按页签加载，使用统一的加载失败提示和重试处理。

当前本地构建中，主入口 JS 文件从 223,227 字节降至约 131 KB，约减少 41%；设置容器 JS 从 91,275 字节降至约 3.65 KB，各页签另行加载。这是入口文件体积对比，不等于启动时间或总资源体积同比减少。

单文件 EXE 每次启动仍需临时展开 Python、Qt/Chromium；经常使用建议下载完整目录 ZIP 并保留 `_internal/`。此次没有移除单文件下载。

## 刷新与图标

- 数据面板同条件刷新保留当前数据与图表 DOM，成功后更新；失败时标记保留上次数据，不把失败刷新当成新的数据更新时间。
- 切换账号、日期和趋势范围时隔离旧数据；过期响应和离开页面后的响应不得覆盖当前画面。
- 图表实例持续复用，窗口 resize 合并到每帧一次；缩短柱状图入场，关闭装饰性常驻脉冲及光晕动画。
- 全局加载提示延迟 300 ms 显示，已显示时至少保留 350 ms，连续请求之间避免瞬间出现/消失。
- 沿用蓝色交叉标识，生成真正透明底 PNG、SVG 和含 16/24/32/48/64/128/256 尺寸的 ICO。窗口、任务栏、托盘与两种 PyInstaller EXE 共用图标，托盘保留小状态点。开发者可安装 Pillow 后运行 `python scripts/generate-app-icon.py` 重新生成。

## 临时界面清理

删除历史 `apps/desktop/ui`、演示宿主/启动脚本、`build:desktop` 配置，以及额外的安全工作台前端和构建入口。旧 `/desktop/safety`、`/desktop-safety.html` 地址返回 404，避免旧 dist 残留页面被静态目录再次提供。正式页面保留原 Vue 后台；库存保护、安全接口和历史 Python 离线回归继续保留，不删除用户 `data/`。
